Privacy policy

Cylinder Tracker is a demonstration tool for reporting and tracking problems with gas cylinders in the Rice University stockroom. It is not an official Rice University service.

What it collects

When someone submits a report: their name, email, optional phone number, the order number, building, room and a description of the problem. Emails sent to and from the tracker mailbox (cylindertracker1@gmail.com) about a report are stored with that report.

How Gmail access is used

The app accesses only its own tracker mailbox. It reads messages sent to that mailbox to attach them to reports, sends emails about reports, and labels messages it has processed. It does not access anyone else's Gmail account, and it does not delete mail. Data obtained through Google APIs is used only to run the tracker and is not sold, shared for advertising, or used to train AI models.

Where it is stored

Report data is stored in a private GitHub repository that only the stockroom administrators can access.

Contact and removal

To ask about or remove your data, email cylindertracker1@gmail.com.
